Created by: Hailey Wong-Budiman, Danica Kim, Lucy Yang, and Serena Chen

## Project Overview:
Meet LockedIn: the first productivity suite that doesn’t just keep you focused, it locks you in with playful nudges, clever redirects, and a little lighthearted chaos.

## Key Features:
Blocks or redirects distracting tabs to keep you focused during a “locked-in” session
<br/>
Plays playful audio cues (music, voice lines) when you go idle 
<br/>
Encourages accountability with streaks, nudges, and fun interactions 
<br/>
Lets you configure session duration, whitelist sites, and to-do list

## Technologies Used:
Javascript, HTML, CSS, Figma
